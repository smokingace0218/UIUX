# Flow: landing page hero

A desktop landing page hero for **Flow**, a fictional productivity app, built for a UI/UX design intern assignment.

> Everything you need to get your work done, without the noise.

![Flow hero](docs/process/07-final-desktop.png)

- **How it was made:** [docs/PROCESS.md](docs/PROCESS.md) covers the AI workflow, each iteration with screenshots, where I directed or corrected the AI, and a reflection.
- **Run it:** `npm install`, then `npm run dev`.
- **Code:** `src/components/FlowHero.tsx`, `src/components/FlowHero.css` and `src/components/SiteHeader.tsx`. The background is ThreeUI's Dimensional Field, in `src/shaders/`.
